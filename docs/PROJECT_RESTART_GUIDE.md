## 從 GitHub 重建

1. 複製 `main`，使用 `package.json` 指定的 Node.js 版本執行 `npm.cmd ci`。先閱讀本文件、`README.md`、`docs/GAME_UI_STANDARD.md`、`docs/TURN_GAMES_ONLINE.md`、`docs/games/`、`.env.example` 與 Git 提交史。
2. 執行 `npm.cmd run check` 與 `npm.cmd run build`；這包含內容、注音、語音、美術檢查、型別及測試。不可停用驗證器來使建置過關。GitHub Pages 的建置需使用專案子路徑 `/kids-board-game-kingdom/`；部署流程見 `.github/workflows/`。
3. 離線與本機玩法可先驗證。雙裝置功能還依賴 Firebase 匿名配對及 Cloudflare Workers；公開設定範例見 `.env.example`，服務與權限說明見線上服務文件。帳號、密鑰及第三方服務狀態不在 GitHub 備份範圍內，應由製作人重新授權並以服務控制台確認，不得索取密碼或推測其仍可用。
4. 清理時未保存本機 `AGENTS.md`、`PROJECT_STATUS.md`、`ART_APPROVALS.md`、`RELEASE_STANDARD.md` 等內部檔案。重啟時以已公開規格與程式實證建立新的本機權威文件；本指南是當時狀態摘要，不冒充完整核准紀錄。若新需求會改變規則、美術、兒童資料、外部服務或公開發布政策，先取得製作人決定。
5. 只把本地檢查、公開部署與製作人 iPhone 實測分開報告。Git 推送、CI 成功或瀏覽器模擬器通過，均不能取代兩支實機的驗收。
