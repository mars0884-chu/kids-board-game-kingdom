## 1. 目的與目前邊界

暗棋是黑白棋完整縱切完成後的下一款棋類。本文件記錄製作人已確認的台灣暗棋規則範圍，包含 NPC 提議和局門檻；規格 Gate 已完成，後續依 `V080-ENGINE` 工作建立規則核心與可重播驗證。

共用 PWA、逐字右側台灣注音、語音、提示、存檔、同機雙人與離線模式沿用既有框架，但暗棋的隱藏資訊與翻牌流程必須另行測試，不能直接套用黑白棋的公開局面假設。

## 2. 製作人已確認的台灣暗棋規則

以下規則依製作人 2026-08-19 指示整理。維基百科的台灣暗棋背景亦記載半個中國象棋棋盤為 4×8 格、32 枚棋子，以及常見的連續 50 步未翻子／吃子和局；本專案仍以製作人指定內容為準，不直接把網頁上的其他變體帶入產品。

參考背景：[維基百科〈暗棋〉](https://zh.wikipedia.org/wiki/%E6%9A%97%E6%A3%8B)

### 2.1 棋盤與棋子組成

- 採中國象棋半個棋盤，4×8 共 32 格。
- 使用完整 32 枚中國象棋棋子：紅、黑雙方各 16 枚，包含將／帥 1 枚、士／仕 2 枚、象／相 2 枚、車 2 枚、馬 2 枚、炮／包 2 枚、兵／卒 5 枚。
- 直式或橫式由響應式版面選擇，以符合手機與平板四種指定畫面；棋盤格保持正方形，不因方向拉伸。
- 棋子正面顯示台灣繁體中文棋子名稱；背面外觀一致，不得從背面辨識棋子或陣營。

### 2.2 翻牌與回合

- 開局將全部 32 枚棋子背面朝上洗亂，隨機擺放於 32 格。
- 第一位玩家翻開第一枚棋子；翻出的顏色決定該玩家陣營：紅子為紅方，黑子為黑方，另一色由另一位玩家控制。
- 每回合只能選擇一項行動：「翻棋」、「走子」或「吃子」。行動完成後換手，不在同一回合串接第二項行動。
- 翻棋：選擇場上任一枚背面朝上的棋子翻開，成為明棋；翻開後依棋子顏色歸屬陣營。
- 沒有可走的己方明棋但仍有背面棋子時，仍可選擇翻棋；沒有可翻棋且沒有合法走子／吃子時，依終局條件判定。

### 2.3 走法與吃子

- 所有普通明棋只能上下左右移動一格，不得斜走；走子目的格必須是空格。
- 只有己方明棋可以行動；普通吃子是移動到相鄰敵方明棋格，將敵子移出棋盤。
- 一般階級由大到小為：將／帥 > 士／仕 > 象／相 > 車 > 馬 > 炮／包 > 卒／兵。
- 普通吃子除例外外採同階或大吃小：較大棋子可吃較小或同階敵子；不得吃較大敵子。
- 兵／卒可以互吃；階級高於兵／卒的士／仕、象／相、車、馬與炮／包都可以吃相鄰敵方兵／卒。兵／卒是將／帥的剋星，可以吃將／帥；將／帥不能反過來吃兵／卒。
- 兵／卒不能吃士／仕、象／相、車、馬或炮／包；其他非炮棋子仍依同階或大吃小判定。
- 炮／包普通平移時與其他棋子相同，只能上下左右移動一格至空格。
- 炮／包吃子時必須沿同一直線上下或左右，隔著剛好一枚棋子作為炮架，再吃掉炮架後方的第一枚敵方明棋；炮架可為任何大小、任何陣營、明棋或暗棋，吃子不受階級限制；不得斜向、轉彎或隔超過一枚炮架。
- 同陣營棋子不得互吃；暗棋不是可直接吃掉的目標，必須先翻開。

### 2.4 隱藏資訊與 NPC 公平性

- NPC 只能讀取玩家已看見的棋面；未翻棋子必須視為未知，不得以預先種子偷看答案後做決策。
- 隨機種子必須能重現整副棋子的配置與翻牌結果，但兒童重播與操作介面不得直接顯示當時尚未看見的棋子資訊。
- 家長／開發者檢視完整局面的工具若日後建立，必須與兒童操作區分離，並明確標示為開發工具。

## 3. 勝負、和局與兒童模式

### 3.1 勝負

- 一方將對方場上所有棋子吃光時獲勝。
- 若對手沒有合法走子，也沒有任何背面棋子可翻時，對手無法行動，視為該方獲勝。
- 終局後不得再翻棋、走子或吃子；結果、剩餘棋子與重玩入口須使用台灣繁體中文、逐字右側台灣注音與台灣語音資產契約。

### 3.2 和局

- 雙方合意可和局。
- 自動和局：使用整局共用的雙方合計計數器；雙方合計連續 50 步沒有翻棋或吃子時判定和局。每一次翻棋、吃子都會將計數歸零，單純走子會使計數加一；不是每位玩家各自累計 50 步。此設定採用台灣暗棋常見的 50 步和局背景。

### 3.3 提議和局按鍵

- 兒童介面新增「提議和局」按鍵；按下後不是立即判定和局，而是送出一個需要對方回應的提議。
- 雙人同樂：另一位玩家看到「接受和局」與「繼續對局」。只有選擇「接受和局」才結束並記錄和局；選擇「繼續對局」則關閉提示並繼續原回合。
- NPC 對戰：當整局雙方合計和局計數達到 40 步以上，NPC 接受「提議和局」；未滿 40 步時，NPC 可回覆「再想一想，繼續對局」。NPC 必須顯示清楚的「接受和局」或「繼續對局」結果，只能依目前已公開的棋面、合法行動與和局計數判斷，不得偷看尚未翻開的棋子。
- 雙人同樂：不受 40 步接受門檻限制，只要另一位玩家按「接受和局」即可結束；40／50 步均為雙方合計步數，不是各自 40／50 步。
- 冒險闖關的教學步驟先教自動 50 步和局；「提議和局」按鍵可在規則解鎖後出現，不用在第一次教學時增加負擔。
- NPC 接受提和的固定門檻為 40 步；不得用隨機或不透明的結果讓兒童猜測。

### 3.4 兒童模式預留

規則確認後，暗棋至少沿用以下共用完成標準：

1. 冒險闖關採「看示範、跟著做、提示練習、獨立完成」，一次只教翻牌、陣營、走法或吃子的一個概念。
2. 自由練習提供入門、成長、挑戰、成人版四階；難度只改變 NPC 決策，不改變暗棋規則或隱藏資訊公平性。
3. 雙人同樂由雙方手動輪流，換手時不可洩漏尚未翻開的棋子。
4. 所有兒童文案、語音、提示、錯誤回饋與結果均須加入結構化內容和逐字右側注音驗證。

## 4. V080-ENGINE 目前狀態與驗證封存

目前已完成的引擎與兒童流程 Machine Gate：

- `src/games/dark-chess/storage.ts` 建立 `adventure`／`npc`／`local` 的 IndexedDB session 契約，保存種子、完整可重播局面、教學步驟與冒險進度；載入仍由回合紀錄重播驗證，不接受局面竄改。
