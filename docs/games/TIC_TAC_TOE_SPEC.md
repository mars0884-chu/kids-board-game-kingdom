# 井字棋完整遊戲規格

規格版次：`TICTACTOE-SPEC-r01`  
對應產品版本：`v0.2.0`  
狀態：核心規格、ART-005-r03 正式美術與完整可玩流程均已完成；等待製作人實機驗證  
適用年齡：以 7 歲兒童為主要對象

## 1. 本版範圍

本版採用標準 3×3 井字棋，先完成一個可離線遊玩的完整學習縱切，包含互動教學、自由練習、四階 NPC、同機雙人、提示、兒童文案、語音、存檔與可重播測試。

本規格不包含進階井字棋、雙裝置連線、公開配對、帳號或雲端資料庫。進階井字棋必須另立規格並由製作人確認規則後才能實作。

## 2. 正式採用規則

1. 棋盤固定為 3 欄×3 列，共 9 格。
2. 兩位玩家使用不同記號，規則核心以 `x` 與 `o` 作為技術識別；兒童畫面的正式棋子造型另由 ART-005 核准。
3. `x` 先手，雙方每回合輪流在一個空格放入自己的記號。
4. 已放下的記號不能移動、堆疊、取代或移除。
5. 率先讓自己的 3 個記號在橫列、直行或對角線連成一直線者獲勝。
6. 棋盤填滿且無人連成一直線時為和局。
7. 對局獲勝或和局後立即結束，不得再落子。
8. 所有模式共用同一規則核心，畫面、教學或 NPC 不得自行改寫合法走法與勝負結果。

## 3. 學習目標

- 看懂輪流與空格才能落子的規則。
- 找出自己下一步可以完成的三連線。
- 看見對手下一步可能完成的三連線並加以阻擋。
- 認識中央、角落與邊格的差異。
- 開始練習同時安排進攻與防守，而不是只看單一格。

## 4. 遊玩模式

### 4.1 互動教學

依序使用「看示範、跟著做、提示練習、獨立完成」：

1. 看示範：棋棋貓示範雙方輪流把記號放進空格。
2. 跟著做：兒童依腳印提示完成一個指定落子。
3. 提示練習：兒童在兩個候選格中找出可完成三連線的位置。
4. 防守練習：找出對手即將連線的位置並阻擋。
5. 獨立完成：進行一局無強制指定落點的入門對局。

每一步只教一個概念，語音可以重播、暫停與略過；未完成教學時可安全返回，重新進入後從最近完成的小節開始。

### 4.2 自由練習

可選擇已解鎖的 NPC 難度，不影響冒險進度。兒童可隨時重開、返回或請求提示。

### 4.3 同機雙人

兩位玩家在同一裝置輪流操作。每步後清楚提示換手，不旋轉整個畫面；平板橫向為主要體驗，手機與平板仍支援四方向。

## 5. 四階 NPC

所有 NPC 都只能讀取公開棋盤，使用與玩家相同的合法走法，且以固定種子重現選擇。

| 難度 | 正式行為 |
| --- | --- |
| 入門 | 看見自己可立即連線時會完成；依固定種子在合理候選中選擇，部分局面會阻擋對手，讓兒童有觀察與補救機會，但不連續做出非法或刻意荒謬的走法。 |
| 成長 | 優先完成自己的連線，其次阻擋對手，再依中央、角落、邊格選擇；相同種子與局面必須得到相同結果。 |
| 挑戰 | 使用完整局面搜尋，在所有最佳走法中依固定種子選擇，保留可重播的行為變化。 |
| 成人版 | 使用完整局面搜尋與固定優先序選擇最佳走法；從合法初始局面出發不得被強迫擊敗。 |

難度只改變 NPC 決策，不改變棋盤、勝利條件或兒童可用操作。升級前由棋棋貓說明增加的挑戰，返回較容易難度不扣除進度或獎勵。

## 6. 四層提示

1. 重述目標：提醒要讓三個自己的記號連成一直線。
2. 指出區域：以外框與圖示指出值得查看的列、行或對角線。
3. 顯示候選：標出一至兩個合法候選格，但不自動落子。
4. 示範一步：先演示建議位置，等兒童自行確認後才完成操作。

提示不得第一時間代替兒童完成整題。使用提示不扣分，回饋著重「看見新的走法」。

## 7. 終局與正向回饋

- 獲勝：肯定觀察與規劃，可顯示不阻擋操作的短暫紙花並允許略過。
- 和局：說明雙方都守住了重要位置，鼓勵再次嘗試不同走法。
- 未獲勝：不顯示「失敗」，使用「你發現了一種走法」或「棋棋貓陪你再想想」。
- 所有終局都提供再玩一次與返回，不以倒數或連勝造成壓力。

## 8. 可序列化局面與重播契約

局面資料至少包含：

- `version`：資料格式版本，目前為 `1`。
- `startingPlayer`：先手，正式模式固定為 `x`。
- `board`：9 格棋盤，每格為 `x`、`o` 或空值。
- `currentPlayer`：下一位行動玩家。
- `phase`：`playing`、`won` 或 `draw`。
- `winner` 與 `winningLine`：終局結果。
- `moves`：依序記錄玩家與 0 至 8 的格位索引。
- NPC 選擇另保存難度與整數種子；不得依賴 `Math.random()` 還原。

載入資料時必須從走棋紀錄重新演算並驗證棋盤與終局，不接受格數錯誤、輪次錯誤、重複落點、終局後加步或遭竄改的結果。

## 10. 兒童文案與語音清單

實作畫面時至少建立下列結構化文案；每一筆兒童文案都必須具有逐字台灣注音、`speech_zh_tw` 與唯一 `audio_asset`：

- 遊戲名稱、模式名稱、四階難度名稱。
- 輪到你、請選空格、這格已經有棋子、換對方、對局暫停。
- 找找可以連成三個的位置、看看對手快連成三個的位置。
- 看示範、跟著做、自己試試看、重播語音、略過示範。
- 連成三個、雙方都守住了、你發現了一種走法、再玩一次、返回。
- 同機雙人的玩家一與玩家二換手提示。

數字、格位與技術識別不得直接裸露給兒童；若介面確實需要顯示數字，必須提供可朗讀的台灣繁體中文語音內容。

## 12. 完成條件

1. 規則核心在無畫面的測試環境通過合法走法、勝負、和局、錯誤復原、序列化與重播測試。
2. 四階 NPC 全部只下合法棋，相同種子可重現，成人版不可從標準初始局面被強迫擊敗。
3. 互動教學、自由練習、NPC 與同機雙人共用規則核心。
4. 所有可見兒童中文字使用既有 `BopomofoText` 逐字配對顯示右側直排注音，並具備語音鍵值。
5. 手機、平板四方向與共用平板橫向的電腦版型通過觸控、溢位與可讀性檢查。
6. ART-005 及實機組合畫面經製作人正式確認後，才可列入正式版本。
