## 1. 本階段目的與範圍

v0.5.0 以「先操作、再看算式」驗證第一款數學遊戲的完整學習循環。玩家先在寶石盤上用手指連出一條路徑，再由系統把實際選到的數字整理成加法或減法關係；遊戲不先顯示一整題文字題要求兒童填答案。

本階段預計包含：

- 可離線遊玩的數字寶石連線規則核心。
- 四關互動冒險教學。
- 自由練習的入門、成長、挑戰、成人版四階。
- 同機雙人輪流操作。
- 四層提示、正向回饋、重玩、返回、暫停與語音按鈕。
- 固定整數種子題目生成、答案驗證、局面序列化與重播。
- 結構化台灣繁體中文、每字右側直排台灣注音與語音欄位。
- IndexedDB 進度與關卡完成狀態；不建立兒童帳號或雲端個人檔案。

本階段不包含：

- 雙裝置連線、後端、帳號、資料庫或公開配對。
- 倒數計時、連勝壓力、扣分、付費、廣告或隨機抽獎。
- 只以文字題庫呈現的算式練習。
- 自由出題編輯器、家長端數據分析或兒童行為上傳。
- 未經製作人確認的新角色、場景、正式寶石素材或其他正式美術。

井字棋、五子棋、黑白棋與暗棋的封存版本與既有正式美術均不修改；共用 PWA 外殼、`BopomofoText`、語音欄位、提示框架、存檔驗證與響應式規範可重用。

## 2. 建議採用的核心玩法

### 2.1 兒童適用的寶石盤大小

「一般小學生能玩多大」沒有適用每個孩子的單一硬性答案；本專案要同時處理 7 歲兒童的注意力、數字加減、路徑規畫、觸控與逐字注音，因此採用保守的產品上限：

| 年齡與用途 | 建議寶石盤 | 本版安排 |
| --- | --- | --- |
| 初次學習、約 6～7 歲 | 3×3，共 9 格 | 第一、二關與自由練習入門 |
| 7 歲兒童的熟悉遊玩 | 4×4，共 16 格 | 第三、四關與自由練習挑戰以上 |
| 較高年級的額外挑戰 | 5×5，共 25 格 | 不納入 v0.5.0；未來另立規格與實機驗證 |

4×4 是 v0.5.0 的一般遊玩上限，不是要求每位兒童一開始就使用的大小。5×5 同時增加掃描範圍、干擾數量與可行路徑，對第一款數學遊戲容易把「學數字」變成「找路迷宮」；即使較大的兒童可能玩得來，也不代表應在本版預設開放。寶石盤大小也不能只看數學能力，還要以實際觸控尺寸、注音可讀性與不使用倒數的操作節奏驗證。

### 2.2 棋盤與寶石

1. 每題使用固定 `3×3` 或 `4×4` 寶石盤；3×3 為 9 格，4×4 為 16 格。
2. 每格有一顆數字寶石，數值為正整數；正式範圍依難度為 `1` 至 `9`。
3. 寶石盤採行、列座標與固定索引，技術索引為 `row * boardSize + column`；兒童畫面不直接顯示技術索引。
4. 連線只能沿上下左右相鄰格移動，不採斜角相鄰；路徑不得跳格。
5. 同一條路徑不得重複選取同一格；玩家可在尚未完成時撤回最後一顆寶石。
6. 棋盤保持正方形；手機直向採寶石盤與操作區上下排列，橫向採左右排列，不能因方向改變而拉伸。

### 2.2 湊數任務：加法與數的組合

題目提供目標數 `target`。玩家連出一條有效路徑，讓所選寶石的總和剛好等於目標數：

```text
所選寶石 2 + 3 + 4 = 目標 9
```

- 只有總和等於目標數才完成。
- 總和小於目標時，可以繼續選相鄰寶石或撤回上一顆。
- 總和大於目標時，不自動清除整題；系統保留路徑並提供撤回，讓兒童看見「多了一些」的原因。
- 任一符合規則的有效路徑都算完成，不接受只由題庫預先指定的唯一答案。

### 2.3 拿走任務：減法與剩下多少

題目提供起始數 `start` 與剩下數 `remaining`。玩家連出一條路徑，選取要拿走的寶石，使：

```text
起始數 14 - 拿走的寶石 5 = 剩下 9
```

規則核心先驗證所選寶石總和是否等於 `start - remaining`，完成後才顯示完整減法關係；兒童不必先輸入抽象的減法答案。

- `0 < remaining < start <= 20`。
- 拿走的寶石總和必須大於 0 且不得超過 `start`。
- 路徑、不可重複、相鄰與多解條件與湊數任務相同。
- 這個題型只在教學完成「拿走」概念後開放；不在第一關同時加入加法與減法。

### 2.4 完成與重玩

- 題目完成後立即鎖定當題，不得繼續選取或改寫已驗證路徑。
- 顯示玩家實際選到的寶石與算式關係，並以正向語句回饋觀察與組合。
- 每題均可重玩；重玩使用相同題目種子與盤面，另提供下一題以新的可重現種子產生。
- 離開、暫停或切到背景時保存題型、種子、盤面、目前路徑、目前總和、提示層級與階段，不因中斷直接判定未完成。

## 3. 題目生成與答案驗證

### 3.1 題目資料契約

每題至少包含：

```ts
interface NumberGemPuzzle {
  version: 1
  id: string
  seed: number
  type: 'combine' | 'take-away'
  boardSize: 3 | 4
  board: number[] // boardSize * boardSize 格，數值 1 至 9
  target: number
  start: number | null
  remaining: number | null
  minPathLength: number
  maxPathLength: number
  solutionCount: number
}
```

- `combine` 題型使用 `target`，`start` 與 `remaining` 必須為 `null`。
- `take-away` 題型使用 `start` 與 `remaining`，`target` 保存為 `start - remaining`，供規則核心驗證；兒童畫面顯示語意化算式，不顯示欄位名稱。
- `board` 必須符合 `boardSize * boardSize` 個正整數；載入時不可接受長度、數值範圍或題型欄位不符的資料。
- `solutionCount` 是由規則核心重新枚舉所得的有效路徑數，不信任外部直接傳入的數字。

### 3.2 固定種子生成

1. `seed` 使用可序列化的非負 32 位元整數；不得使用 `Math.random()` 作為不可重播的來源。
2. 生成器使用固定的整數亂數演算法與固定候選順序；相同 `seed`、難度與題型必須產生完全相同的盤面、目標與解法集合。
3. 先建立候選盤面，再由規則核心枚舉所有不重複、上下左右相鄰的簡單路徑；v0.5.0 路徑長度限制為 2 至 4 顆。
4. 正式一般題目至少要有兩條不同座標路徑能完成；不同路徑即使數值排列相同，也仍是兒童可採用的不同操作解法。
5. 生成器找不到符合條件的題目時必須回報可診斷錯誤，不得偷偷降低數值範圍、解法數量或改用非固定亂數。
6. 冒險教學使用明確登記的固定題目資料；固定題目仍須通過同一套答案驗證，不可由畫面自行判定完成。

### 3.3 合法路徑驗證

給定盤面與路徑 `path` 時，規則核心依序檢查：

1. 路徑至少包含 2 格，且不超過當題的最大長度。
2. 每個索引均為 `0` 至 `board.length - 1` 的整數。
3. 不可有重複索引。
4. 相鄰兩格的行差與列差總和必須為 1。
5. 所選寶石總和等於 `target`；拿走任務的 `target` 必須等於 `start - remaining`。
6. 題目未完成前允許回退最後一格；完成後任何新增、修改或刪除路徑的操作都必須被拒絕。

規則核心不讀取 React 元件狀態來決定答案；畫面只提交序列化的題目與路徑，並呈現規則核心回傳的結果。

## 4. 兒童學習目標與四關冒險

### 4.1 學習順序

依序從「看見數字」進入「連續操作」、「數的組合」、「拿走後剩下」與「多種解法」。一次只引入一個新概念；不以成人數學術語取代實際操作。

### 4.2 固定教學關卡

| 關卡 | 學習目標 | 建議題型與範圍 | 完成條件 |
| --- | --- | --- | --- |
| 第一關：認識寶石數字 | 看懂每顆寶石代表多少 | 3×3 湊數；目標 5 至 8；2 顆路徑 | 連出任一有效路徑並說出合計 |
| 第二關：連著走 | 理解上下左右相鄰與不能跳格 | 3×3 湊數；2 至 3 顆路徑；目標不超過 10 | 以相鄰路徑完成目標 |
| 第三關：換到一般寶石盤 | 在 4×4 盤上找出不只一種湊數方法 | 4×4 湊數；目標 8 至 15；2 至 3 顆路徑；至少 2 條解法 | 任選有效解法完成，不限指定答案 |
| 第四關：拿走一些 | 用實物理解減法與剩下數量 | 4×4 拿走；`start` 10 至 15；`remaining` 3 至 10 | 選取拿走路徑並看見減法關係 |

冒險模式不顯示難度選擇，也不以倒數或失敗標籤施壓。每關可重玩；完成後保留智慧星章與最近完成的小節。第四關完成後，混合題型交給自由練習，不再增加第五、第六關。教學流程仍採「看示範、跟著做、提示練習、獨立完成」。

## 5. 自由練習與同機雙人

### 5.1 自由練習四階

自由練習沿用共用難度名稱，但難度只改變題目範圍、路徑長度、干擾配置與提示預設，不改變合法路徑規則或答案公平性。

| 難度 | 建議範圍 |
| --- | --- |
| 入門 | 3×3、以湊數為主；目標 5 至 10；2 顆路徑；提示較明顯；至少 2 條有效解法 |
| 成長 | 3×3、湊數為主並少量加入拿走；數值上限 15；2 至 3 顆路徑；至少 2 條有效解法 |
| 挑戰 | 4×4、混合題型；數值上限 20；2 至 3 顆路徑；干擾寶石增加；至少 2 條有效解法 |
| 成人版 | 4×4、混合題型；數值上限 20；2 至 4 顆路徑；提示預設較少；仍無倒數與懲罰 |

### 5.2 同機雙人

1. 兩位玩家在同一裝置輪流解題；不使用 NPC，不顯示 NPC 難度。
2. 每位玩家的回合使用獨立新種子與新盤面，避免第一位玩家的完整解法直接洩漏給第二位。
3. 預設每位玩家各完成三題，共六題；兩位玩家都可獲得完成星星，不以勝負或扣分標籤作為主要回饋。
4. 換手時只顯示目前玩家與必要操作提示，不旋轉整個畫面；平板橫向為主要體驗，手機與平板四方向均支援。
5. 離開或暫停時保存目前玩家、題目種子、盤面與路徑；恢復後不得替玩家自動完成題目。

## 6. 四層提示與回饋

提示順序沿用共用框架：

1. **重述目標**：說明要湊到多少，或要拿走多少才會剩下目標數。
2. **指出區域**：以不覆蓋數字的外框或柔和圖示指出值得觀察的寶石區域。
3. **顯示候選**：標出一至兩顆可能的起點或下一步，不直接標出完整答案路徑。
4. **示範一步**：棋棋貓示範第一步，兒童仍須自己完成其餘路徑與確認。

提示不得自動選取整條路徑、替兒童完成題目或因使用提示扣除獎勵。總和超過目標時，回饋說明「多了一些，可以退回最後一顆再想想」，不使用責備或失敗標籤。

## 7. 可序列化局面、存檔與重播

局面至少包含：

- `version`：資料格式版本，目前預定為 `1`。
- `mode`：`adventure`、`practice` 或 `local`。
- `puzzle`：完整可重建的題目資料與 `seed`。
- `path`：目前已選取的格位索引序列。
- `currentTotal`：由盤面與路徑重新計算的目前總和，不信任外部快取值。
- `phase`：`playing`、`completed` 或 `paused`。
- `hintLevel`：目前提示層級。
- `player` 與雙人回合資料；冒險關卡完成狀態與智慧星章另存本機進度。

載入時必須重新生成或驗證題目、重新計算總和、重新檢查路徑相鄰性與題型關係，拒絕盤面長度錯誤、路徑重複、非法跳格、題目種子不一致、完成後新增步驟或遭竄改的存檔。

重播記錄至少包含題目 `seed`、題型、依序操作的格位、回退操作、提示事件與完成結果；相同版本、題型、難度與種子必須重建相同盤面與有效解法集合。

## 8. 結構化兒童文案與語音

正式實作才新增畫面實際需要的內容；每筆 `audience: "child"` 必須具有：

- 台灣繁體中文 `text_zh_tw`。
- 每一個中文字自己的逐字台灣注音 `segments`。
- `speech_zh_tw`。
- 唯一 `audio_asset` 或明確的裝置語音鍵值。

預計文案範圍包含：

- 遊戲名稱、三種模式名稱、四階難度名稱。
- 目標數、起始數、剩下數、目前合計與完成算式的可朗讀語意。
- 請選相鄰寶石、再找一顆、退回最後一顆、剛剛好、多了一些與還差一些。
- 看示範、跟著做、自己試試看、提示四層、再玩一次、返回、暫停與換手。
- 完成、再次嘗試與鼓勵觀察的正向回饋。

數字與運算符號若在兒童畫面出現，必須有可朗讀的 `speech_zh_tw`；不能只把技術數值裸露在畫面或語音中。每個中文字仍使用既有 `BopomofoText` 逐字右側直排注音，窄版只能讓完整配對一起換行，不得改成上下兩行或隱藏必要注音。

固定台灣真人錄音／可驗證台灣 TTS 資產仍沿既有延期決策；本階段保留語音欄位與語音按鈕，不把瀏覽器預設 SpeechSynthesis 宣稱為固定台灣發音。

## 9. 美術與介面邊界

- 直接重用已核准的 ART-003-r03 首頁方向與 ART-004-r03 共用兒童 UI，不重開既有核准美術。
- 寶石盤、數字寶石、選取路徑、目標牌、算式回饋與教學圖示若要成為正式產品美術，必須建立新的 ART 提案並由製作人確認。
- 在核心規格與規則測試期間，只能使用可逆的程式／SVG 技術佔位；不得把佔位素材稱為正式美術、放入正式封存或推定已核准。
- 主要互動目標至少 48×48 CSS px；路徑選取須同時有色彩、形狀或圖示差異，不只依賴紅綠色。
- 選取路徑的亮度、動畫與音效可關閉或降低，不得持續閃爍或阻擋下一步操作。
- 四方向驗證須確認寶石盤正方形、數字清楚、路徑不互疊、控制區無水平／垂直溢位，並保留 Edge 主要、Chrome 交叉驗證。

## 10. 固定測試案例與 Machine Gate

### 10.1 規則與生成器測試

| 編號 | 測試 | 預期結果 |

| NG-R11 | 終局後操作 | 完成後新增、刪除或改路徑均被拒絕 |
| NG-R12 | 存檔竄改 | 路徑、盤面、種子或總和不一致時拒絕載入 |

### 10.2 模式與兒童流程測試

- 四關教學依序只引入一項新概念，可重玩、可返回、可暫停與可重播語音。
- 冒險不顯示自由練習難度；自由練習顯示四階；同機雙人不顯示 NPC 難度。
- 提示四層只增加引導，不自動完成整題；提示不扣星星。
- 同機雙人每回合使用獨立可重現題目，換手不洩漏下一位的題目解法。
- `BopomofoText`、內容檢查、逐字注音版型檢查、語音欄位與台灣繁體中文檢查均為阻擋條件。
- IndexedDB 中斷恢復、返回、暫停、離線重開與重播均不破壞題目或進度。
