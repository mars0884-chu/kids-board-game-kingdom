# 五子棋完整遊戲規格（草案）

規格版次：`GOMOKU-SPEC-r01`  
對應產品版本：`v0.3.0`  
狀態：核心規則已由製作人確認；進入規則引擎 Machine Gate   
適用年齡：以 7 歲兒童為主要對象

## 1. 本階段目的

本規格是 v0.3.0 五子棋完整遊戲縱切的唯一規則草案。先完成規則、學習目標、模式、難度、提示、資料契約與測試邊界，再進入規則核心與畫面實作；不得先做只有棋盤與基本落子的半成品。

井字棋 v0.2.1 已完成並封存。本版只重用已驗證的共用回合介面、`BopomofoText`、語音欄位、存檔／重播契約、難度選擇與提示框架，不修改 v0.2.1 封存產物。

## 2. 正式採用規則

製作人已確認採用下列規則。棋盤規則固定，不因裝置尺寸改變；裝置只負責以響應式方式縮放與安排操作區。

1. 棋盤為 15×15 個交叉點，共 225 個落子位置。15×15 是國際 Renju 常用的標準棋盤；不盲目增加到 19×19，避免手機版每個落點過小而破壞兒童可操作性。正式 Machine Gate 會以手機直向、手機橫向、平板直向、平板橫向與電腦共用平板橫向版型驗證落點可讀性與觸控範圍。
2. 黑方固定先手，白方後手。
3. 任一方在橫向、直向或斜向形成連續五子即獲勝；黑方必須恰好五子，形成六子以上長連線不算黑方勝利，並視為禁手。白方形成五子以上即可獲勝。
4. 黑方不得落出長連線（六子以上）、雙三或雙四。禁手落點不屬於合法走法；若黑方只能落禁手，仍須由規則核心依局面判定，不得由畫面自行放行。
5. 「雙三」與「雙四」依 Renju 的連續線定義判定；只有同一落點同時形成兩個或以上有效三線／四線才算禁手，不能只用相鄰棋子數量粗略猜測。
6. 黑方落點同時形成恰好五子與其他三／四線時，恰好五子優先視為黑方獲勝；長連線仍是禁手。這項優先序會寫入規則測試，避免終局歧義。
7. 棋盤填滿且沒有任何一方達成勝利條件時為和局。
8. 對局獲勝、和局或黑方禁手終局後立即結束，不得再落子；所有模式共用同一規則核心。

採用禁手的原因：黑方固定先手會天然具有較大開局優勢；Renju 以黑方的長連線、雙三、雙四限制平衡先手優勢，同時保留五子棋的連線觀察與攻防學習目標。教學不要求兒童一開始背誦競賽術語，會以「這一步同時打開太多路，換一個位置試試看」等兒童文案與候選提示逐步說明；成人版與規則說明頁才提供完整名稱。

## 3. 建議的兒童學習目標

- 看懂輪流落子與棋盤上的空格。
- 找出自己可以連成五子的方向。
- 觀察並阻擋對手即將完成的連線。
- 理解橫向、直向與斜向的連續關係。
- 從局部連線逐步學習同時安排進攻與防守。

正式題目數量、用語與教學節奏依核准規則調整，不先假定兒童必須理解成人競賽術語。

## 4. 預定遊玩模式（規則確認後實作）

### 4.1 互動教學

依序採用「看示範、跟著做、提示練習、獨立完成」：

1. 認識棋盤、棋子與輪流落子。
2. 觀察一條連線如何形成。
3. 在提示下找出自己的完成位置。
4. 在提示下阻擋對手的完成位置。
5. 完成一局入門對局。

入門教學只使用正式核准的規則；不以降低規則正確性換取操作簡化。

### 4.2 自由練習

可選擇已解鎖的入門、成長、挑戰、成人版四階 NPC；難度只改變 NPC 決策，不改變棋盤、勝利條件或玩家合法操作。

### 4.3 同機雙人

兩位玩家在同一裝置輪流操作。平板橫向為主要體驗，手機與平板四方向均需支援；換手提示不得洩漏尚未輪到玩家的必要資訊。

### 4.4 冒險闖關

冒險闖關是獨立的固定關卡制，不顯示 NPC 難度選擇，也不得把自由練習畫面宣稱為冒險內容。玩家可隨時從關卡列重玩任何一關；每關完成後保留一枚本機智慧星章，並可進入下一關。

| 關卡 | 固定學習目標 | 初始局面與完成位置 | 提示層級 | 完成條件 |
| --- | --- | --- | --- | --- |
| 第一關：連成五子 | 看出自己的四連並補成五子 | 黑方第 8 列第 8 至 11 點；可落第 8 列第 7 或第 12 點 | 重述目標 → 連線兩端 → 兩個候選格亮起 → 示範其中一格 | 黑方以任一端形成恰好五子獲勝 |
| 第二關：守住連線 | 阻擋白方唯一的五連點 | 白方第 8 列第 8 至 11 點；黑方落第 8 列第 12 點 | 同上 | 目標格被黑方阻擋 |
| 第三關：打開四子 | 找到可兩端延伸的四子線 | 黑方第 8 列第 5 至 7 點；落第 8 列第 4 或第 8 點 | 同上 | 形成兩端皆可延伸的四子線 |
| 第四關：避開禁手 | 認識黑方雙三禁手並換另一個位置 | 中央十字三子預備局；中央點為雙三禁手 | 重述禁手 → 指出棋線 → 星光示範格 → 示範格 | 不落禁手，任選任一個合法空位完成 |

第一至第三關的錯誤合法位置不會落子，棋棋貓會提醒目前目標；第四關的任何合法非禁手空位皆可落子並完成關卡。禁手位置同樣不會落子，並沿用正式禁手原因回饋。固定局面、目標位置、順序與完成判定必須由規則核心測試；關卡存檔必須保存目前關卡、局面、提示層級與已完成星章。

## 5. 四階 NPC 邊界

正式規則確認後，四階 NPC 必須：

- 只讀取玩家可見的正式局面與已公開走棋。
- 只選擇規則核心判定為合法的落點。
- 使用固定整數種子或可序列化決策資料，讓相同局面、難度與種子可重播。
- 以不同搜尋深度、候選範圍、評估雜訊或策略優先序呈現難度差異，不偷偷改棋盤、改亂數或讓非法步驟通過。
- 入門級提供可理解的觀察與補救機會；成人版則以正式規則下的最佳或明確可重現策略為目標。

## 6. 提示與正向回饋

四層提示沿用共用框架：重述目標、指出區域、顯示候選、示範一步。提示不得直接替兒童完成整題，也不得以扣分、倒數或羞辱訊息施壓。

終局回饋應肯定觀察、嘗試與進步；未獲勝時使用可再次嘗試的兒童友善文案，並提供返回、語音重播與暫停工具。

## 7. 可序列化局面與重播契約（草案）

正式規則核准後，資料至少包含：

- `version`：資料格式版本。
- `boardSize`：核准的棋盤邊長。
- `startingPlayer` 與 `currentPlayer`。
- `board`：依固定索引序列化的棋盤。
- `phase`：`playing`、`won` 或 `draw`。
- `winner`、`winningLine` 與必要的終局證據。
- `moves`：依序記錄玩家與落點索引。
- NPC 難度與固定整數種子。

載入時必須由走棋紀錄重新演算並拒絕重複落點、錯誤輪次、終局後加步、非法勝利線、棋盤尺寸不符或遭竄改的結果。

## 8. 結構化兒童文案與語音

正式實作至少需要遊戲名稱、模式名稱、四階難度、輪到你、請選空格、連線目標、阻擋提示、換手、暫停、重播、返回、再玩一次與正向終局回饋等文案。每筆 `audience: child` 資源都必須具備：

- `text_zh_tw`。
- 每個中文字自己的逐字台灣注音配對。
- `speech_zh_tw`。
- 唯一 `audio_asset` 或明確的裝置語音鍵值。

所有畫面文字沿用正式 `BopomofoText` 鎖定：注音直排在自己的中文字右側，短操作名稱保持單行，窄版只能以完整配對重排，不得改成上下兩行或縮成不可讀文字。

## 9. 美術與介面邊界

- 直接重用已核准的 ART-003-r03 首頁與 ART-004-r03 共用 UI，不改變其方向。
- 五子棋棋盤、棋子、合法落點、連線狀態、教學圖示與新場景屬新正式美術範圍；需建立新的 ART 編號並依正式流程一次提供可進產品的 React／CSS／SVG 或足夠解析度素材與實機組合畫面。
- 新美術未經製作人核准不得進入正式封包；內部線框只能作尺寸、效能與互動測試。
- 棋盤保持正方形；直向上下排列，橫向左右排列；電腦沿用平板橫向版型，不建立獨立電腦素材。

## 10. Gate 與完成條件

### Producer Gate

- 新五子棋正式美術方向與素材。
- 新五子棋正式美術方向與素材。
- 任何會改變產品方向、兒童學習策略、獎勵或資料處理的方案。

### Machine Gate

- 規則核心合法走法、勝負、和局、黑方長連線／雙三／雙四禁手、錯誤復原、序列化與重播測試。
- 四階 NPC 合法性、固定種子重現、公平性與回應時間測試。
- 互動教學、自由練習、同機雙人、提示與存檔整合測試。
- 內容逐字注音、語音鍵值、頁面溢位、棋盤比例、觸控尺寸、Edge 四方向 smoke test、`npm.cmd run check`、`npm.cmd run build`、封包完整性、SHA-256 與乾淨解壓重驗。

### 完成定義

只有正式規則、必要美術與工作本身要求的全部 Gate 完成後，v0.3.0 工作才能標記 `DONE`。若核心規則已確定但只剩美術核准，工作應標記 `WAITING_FOR_PRODUCER`，不得以 Machine Gate 通過代替美術核准。
