# 全遊戲共用介面規範

版本：ART-013-r01（製作人已確認方向）
適用範圍：首頁遊戲入口、教學、冒險、自由練習、同機雙人、連線遊戲及後續新增遊戲。

## 目的與不變原則

讓兒童在不同棋類中能沿用相同操作習慣：按鍵角色、觸控尺寸、圖示語言、字級／注音比例、資訊順序與回饋卡一致。共用的是介面語法，不是把棋盤、棋子、遊戲規則或每款必要按鍵全部做成相同；不加入只為排版而存在的按鍵，也不隱藏必要操作。

已核准的各款棋盤、棋子、角色及其專屬色彩維持原樣。共用控制層使用本文件的語意色與形狀；除製作人明確要求外，不重畫、重染或替換已核准素材。

## 共用控制

| 角色 | 共用呈現 | 尺寸基準 |
| --- | --- | --- |
| 主要行動 | 紫色主色、清楚圖示與完整短文案 | 最小高度 56px |
| 次要行動 | 黃色／奶油色次色；不搶過主要行動 | 最小高度 52px |
| 提示行動 | 藍色提示色，並保留提示圖示 | 最小高度 52px |
| 工具／返回／語音等 | 淺色底、共用描邊與圖示筆畫 | 最小觸控範圍 48×48px |
| 難度選項 | 入門、成長、挑戰、成人版；沿用固定形狀、圖示與選取外框 | 每項最小高度 56px；窄版改排，不縮小至難辨 |
| 首頁模式／棋種入口 | 同一張卡片結構；藍、薄荷、珊瑚只作一致的識別色變體 | 圖示框、圖示、文字與圓角共用響應式 token |

- 控制圓角、外框厚度、間距、陰影層級、語意配色、入口卡片與圖示尺寸由 `src/styles.css` 的共用 token 控制；遊戲不得用小於 48px 的觸控目標補救版面。
- 圖示採同一組 48×48 SVG viewBox、相同筆畫端點和線寬。功能同時以圖形與文案／狀態呈現，不只靠顏色辨識。
- 遊戲入口卡片在各螢幕方向可改變尺寸與排列，但同一 viewport 內不得因棋種而使用不同字級、圖示大小或卡片形狀；每款原核准棋盤／棋子美術維持其辨識特徵。
- 所有控制文案使用同一響應式字級 token，短名稱盡量單行完整顯示。空間不足時依序重排控制、增加列數或讓資訊區捲動；不得裁字、縮成小字、拆散漢字與注音或以空白格補齊。
- 難度圖示不可因手機窄版而消失；須改用兩欄或重新排列。
- 依遊戲需要只顯示真正可用的功能。提示、語音、返回、暫停／繼續等按鍵由各模式功能決定，不為視覺一致而額外新增。

## 注音與文字比例

- 所有兒童文字沿用 `BopomofoText`：每個中文字右側直排自己的台灣注音，漢字與注音作為不可拆開的配對。
- 共用注音字級為漢字字級的 `0.43em`，漢字與注音欄距為 `0.14em`；聲調位置、Unicode 與逐字文案契約仍由既有注音規範及驗證器鎖定。
- 象棋標題、回合、操作、教學文字與棋盤外所選棋子名稱使用共用比例。象棋棋子圓面只顯示置中的單一國字，是製作人已核准的狹義例外；暗棋翻開棋面同樣維持已核准的置中國字呈現。兩者的結構化注音與語音資料仍保留。
- 圍棋黑白棋石不放漢字；棋種、路數、回合、玩家與操作文字一律用共用比例。

## 版面、圖示與棋盤

- 固定驗收尺寸為手機直向 390×844、手機橫向 844×390、平板直向 768×1024、平板橫向 945×768；實際裝置安全區要計入。
- 直向優先採標題／狀態、棋盤、教學／回饋、操作的清楚垂直層級；橫向在空間允許時採資訊與操作在一側、完整棋盤在另一側。不得為了共版型裁切棋盤或拉伸非正方棋盤。
- 棋盤與控制各自按棋類比例縮放；棋子／棋格可因路數調整大小，但觸控命中區仍至少 48px，且需驗證相鄰棋子不互相覆蓋。
- 色彩依共用角色分工：靛青／深色文字與外框、奶油／淺色內容面、紫色主要行動、黃色次要行動、藍色提示、青綠正向回饋。棋類棋子、棋盤材質及玩家辨識色仍可依核准美術保留；任何重要狀態須再配合圖示、形狀或文字。
- 動畫不阻擋操作，互動狀態須同時提供可見外框／形狀變化，支援鍵盤焦點與減少動態效果。

## 圍棋路數決策

製作人已確認圍棋的路數對應：既有四階難度中，入門使用 9 路、成長與挑戰使用 13 路、成人版使用 19 路。同機雙人與雙裝置連線都採相同路數選擇原則；開局前選擇，對局開始後固定該棋盤大小，連線雙方使用同一設定。此為核准的產品方向；圍棋規則引擎、教學、難度與路數選擇流程尚未因此自動視為完成或上線。

## 完成檢核

每次共用元件或遊戲 UI 變更至少執行內容／注音驗證、型別檢查、自動測試與正式建置；並用四種固定 viewport 核對實際程式畫面、頁面溢位、文字完整性、注音比例、觸控尺寸、圖示一致與棋盤比例。公開部署完成以 GitHub Actions 成功及公開網址載入新 bundle 分別確認，不以本機建置代替。
