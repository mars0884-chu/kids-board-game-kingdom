# 綜合兒童棋藝大冒險 v0.9.1

這是提供 7 歲兒童使用的離線優先 PWA 棋藝遊戲。v0.9.1 承接已由製作人確認合格的 v0.7.3 跳棋與 v0.9.0 WebRTC 直連驗證，修訂連線頁中文字／注音比例與四尺寸版面；仍不使用本專案伺服器／雲端。甲分享邀請連結，乙開啟後自動產生回覆連結並只按一次「一鍵回覆給甲」，甲開啟回覆連結後自動連線。目前 WebRTC 僅整合跳棋；其他棋類尚未接入連線，原有離線／同機雙人模式不受影響。跳棋仍是標準 121 孔六角星棋盤、雙方各 10 枚、一般移動／連跳、目標營陣鎖定、六關差異化互動教學、四階兒童友善自適應難度 NPC、同機雙人與 IndexedDB 存檔；不設定人工回合上限。所有兒童文案維持台灣繁體中文、每字右側直排台灣注音與語音欄位。

本版跳棋畫面沿用 ART-010-r01 已核准的正式美術／版面方向；連線頁按鍵沿用共用按鍵的配色、圖示與漢字／右側直排注音契約，並以四個指定尺寸確認不溢出。完整 v0.9.1 可試玩驗證封包包含原始碼、dist、測試、啟動器、版本說明與內容雜湊；v0.9.0 封包保留不修改。v0.7.0～v0.7.2 的跳棋封包、SHA-256 與版本專屬預覽已依製作人授權清理，只保留 v0.7.3；v0.6.7 動物棋、v0.5.5 數字寶石連線與 v0.4.23 暗棋完整封存維持不變。

本版不建立雲端儲存或伺服器，也不建立帳號、房間資料庫、QR Code、第三方額度或兒童個人資料。雙裝置連線只在兩台裝置間使用 WebRTC data channel；邀請／回覆 URL 只短期攜帶連線資料，甲原本的遊戲分頁必須保持開啟。沒有 STUN／TURN 時，部分 NAT、防火牆或行動網路可能無法直連；失聯時保留本機最後局面，但需要重新交換連結。完整範圍與限制見 `docs/P09_ONLINE_SPEC.md`。

## 開啟完整驗證

1. 完整解壓縮 ZIP，不要直接在壓縮檔內執行。
2. 目前工作區先以 `npm.cmd run dev -- --host 127.0.0.1 --port 5173` 啟動 v0.9.1，或在首頁依序選「雙裝置連線」→「跳棋」。跳棋直接預覽可使用 `?preview=jump-chess-adventure`、`?preview=jump-chess`、`?preview=jump-chess-local`、`?preview=jump-chess-online`；完整驗證封包位於 `releases/kids-board-game-kingdom-v0.9.1.zip`。
3. 跳棋四個驗證尺寸為 390×844、844×390、768×1024、1024×768。冒險教學提供六關互動課程；第二至第四關指定不同位置並以金色外圈提示起始棋子，第五關不顯示數字路徑；`jump-chess` 提供四階 NPC 難度；`jump-chess-local` 提供同機雙人。請確認標準 121 孔六角星、下方第一位玩家先手、雙方各 10 枚、一般移動／連跳與結束回合；四尺寸不拉伸棋盤、不產生頁面溢位，棋孔命中區至少 48px，並實際點擊棋子中心確認不會被相鄰透明棋孔攔截。舊動物棋、暗棋、黑白棋與數字寶石連線入口仍可使用原有參數。
4. 啟動器會讀取封包內版本號，使用隨機暫時本機連接埠，並只接受屬於本封包版本的伺服器；實際網址會顯示在命令視窗中。請保持驗證伺服器視窗開啟。
5. 暗棋請查驗：冒險闖關六關可逐關操作並重玩；自由練習顯示入門、成長、挑戰、成人版四階，且挑戰是一層／八候選、成人版是兩層／六候選；雙人同樂不顯示 NPC 難度且雙方手動。四個指定 viewport 均應在視窗內完整顯示、不需頁面捲動、無水平溢出，返回／聽一聽同列、暫停下一列填滿，每個中文字與其右側直排注音保持不可拆配對、略小但清楚且不互疊。首頁一般流程仍是「選擇模式 → 選擇棋類」，其他遊戲可執行 `START_VERIFICATION.cmd gomoku` 或 `START_VERIFICATION.cmd tic-tac-toe`。

### 雙裝置連線驗證

1. 甲開啟 `?preview=jump-chess-online`，按「分享邀請連結」，並保持這個遊戲分頁開啟。
2. 乙點開邀請連結；畫面會自動準備回覆連結，乙只按一次「一鍵回覆給甲」並把連結傳給甲。
3. 甲點開回覆連結；回覆頁會自動把資料交回甲原本的遊戲分頁，雙方不需再按連線鍵。
4. 連線完成後，甲移動一個合法棋步，確認乙收到相同棋盤與回合切換。若要使用自動化瀏覽器驗證，執行 `npm.cmd run verify:jump-chess-webrtc`。

連線頁四尺寸版面回歸可執行 `npm.cmd run verify:jump-chess-online-layout`；它會以 Edge DPR 1 實際檢查 390×844、844×390、768×1024、1024×768 的頁面與按鍵內文邊界。

需要 Windows、Node.js 24 或更新版本，以及可開啟本機網址的瀏覽器。請勿直接開啟 `index.html` 或 `dist/index.html`，必須透過啟動器啟動本機伺服器。v0.6.7、v0.5.5、v0.4.23 與其他保留版本的封存 ZIP／SHA-256 均位於 `releases/`；各版本 ZIP 內的 `MANIFEST.sha256` 記錄內容雜湊。v0.6.0～v0.6.6 的封存 ZIP／SHA-256 與版本專屬動物棋預覽已依製作人 2026-08-30 授權清理，歷史決策紀錄仍保留。v0.5.0～v0.5.4 的封存 ZIP／SHA-256 與版本專屬預覽已依製作人 2026-08-27 授權清理，歷史決策紀錄仍保留。v0.4.23 與更早保留版本不得修改。
